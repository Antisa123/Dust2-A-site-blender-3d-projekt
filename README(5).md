# Dust II – A Site

**Dust II – A Site**

3D scena A Site područja mape Dust II izrađena u Blenderu.

## O projektu

Cilj projekta bio je izraditi 3D scenu A Site područja mape Dust II, uključujući modeliranje, teksturiranje, rasvjetu i animaciju kamere.

## Korišteni alati

Blender 5.2 LTS — modeliranje, teksturiranje, rasvjeta i render

## Tehnike korištene u projektu

3D modeliranje
UV mapping
PBR teksture
Materijali i rasvjeta
Animacija kamere
