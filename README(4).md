# Dust II – A Site

**Dust II – A Site**

3D scena A Site područja mape Dust II izrađena u Blenderu, inspirirana igrom Counter-Strike 2.

## O projektu

Cilj projekta bio je izraditi i prezentirati 3D scenu A Site područja mape Dust II. Projekt uključuje modeliranje objekata i prostora, teksturiranje, UV mapping, materijale, rasvjetu te animaciju kamere.

Tijekom izrade korišten je Blender, a dio rada odnosio se na samostalno učenje i rješavanje problema vezanih uz modeliranje, UV mapping, teksture, materijale i kameru.

## Korišteni alati

Blender 5.2 LTS — modeliranje, teksturiranje, materijali, rasvjeta, kamera i render

## Tehnike korištene u projektu

Modeliranje 3D objekata  
UV mapping i unwrap  
PBR teksture i materijali  
Rasvjeta i noćna scena  
Animacija kamere
